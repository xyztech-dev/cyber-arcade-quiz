# ⚡ CyberArcade Quiz App

An interactive, vibrant gaming-themed quiz web application built with a modern cyberpunk aesthetic. Designed as a standalone web project, this app features dynamic category selection, live countdown timers, instant visual feedback, and comprehensive performance evaluations.

🔗 **Live Demo:** [https://xyztech-dev.github.io/cyber-arcade-quiz/](https://xyztech-dev.github.io/cyber-arcade-quiz/)

---

## 🚀 Key Features

* **Dynamic Category Selection:** Users can choose their challenge domain before launching the diagnostic assessment:
  * 🎮 **Gaming & Esports** (Covers mobile battle royales, hardware grips, performance metrics, and racing titles)
  * 💻 **Web Dev & Tech** (Covers HTML, GitHub workflows, JavaScript bindings, and Linux terminal tools)
  * ⛩️ **Anime & Lore** (Covers popular series mechanics, breathing styles, and mythic comic lore)
* **Per-Question Countdown Timer:** A 15-second timer per question that shifts into a flashing warning state during the final seconds. If time expires, the app auto-locks and reveals the correct answer.
* **Instant Visual Feedback:** Interactive option buttons immediately highlight correct choices in neon green and incorrect attempts in vibrant red, accompanied by detailed technical analysis explanations.
* **Rank & Score Reporting:** Calculates final performance metrics dynamically and awards tactical ranks ranging from **Rank S+ (Legendary Mastery)** down to **Rank C**.
* **Neon Cyberpunk Aesthetic:** Built with CSS custom properties, glassmorphism blur filters, Google Fonts (`Orbitron` & `Rajdhani`), and smooth glowing hover transitions.

---

## 🛠️ Built With

* **HTML5** – Structured semantic layout and screen containers.
* **CSS3** – Custom flexbox layouts, neon glow variables, keyframe animations, and responsive styling.
* **Vanilla JavaScript (ES6+)** – Dynamic question rendering, state management, category routing, and real-time countdown loops.
* **GitHub Pages** – Zero-cost, continuous deployment hosting.
